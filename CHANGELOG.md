# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-25

### Added

- NumPy implementations of StandardScaler and reproducible train/test splitting
- Gradient-descent Linear Regression with convergence and loss history
- Euclidean-distance KNN with deterministic tie handling
- Multi-start K-Means with inertia and safe empty-cluster recovery
- Covariance-eigendecomposition PCA with inverse transformation
- Regression and classification metrics
- Reproducible CLI demos, reference comparisons, and PNG visualizations
- Automated tests, Ruff quality checks, and GitHub Actions CI
- Mathematical notes, limitations, and delivery documentation
